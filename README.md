# RR ROAD TRIPS

Responsive car rental and travel services website for a Hyderabad-based operator.

## Scripts

- `npm run dev` — start the local dev server
- `npm run build` — typecheck and create a production build
- `npm run preview` — preview the production build
- `npm run lint` — run oxlint

The booking form validates in the browser and shows a confirmation message. `submitBookingRequest` in `src/lib/booking.ts` is the place to connect a backend later.
